## How to use buttons

HRIV uses MUI `Button` directly. Prefer MUI variants and theme colours before adding custom styles. Use custom `sx` sparingly for layout-specific affordances such as the login form's text actions.

## Guidance

- Use `contained` for primary call-to-action buttons, including OIDC sign-in.
- Use `outlined` for secondary actions that still need visible affordance.
- Use `text` for compact inline actions, links, and low-emphasis form actions.
- Use `startIcon` for actions whose purpose benefits from a visual cue.
- Disable buttons while async work is pending; pair with a spinner when progress is useful.
