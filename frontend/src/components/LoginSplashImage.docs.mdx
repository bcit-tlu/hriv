## When to use

Use `LoginSplashImage` as the right-hand visual panel in the login layout. It is decorative (`aria-hidden`) and hidden below the medium breakpoint so mobile users focus on the form.

## Interactive example

<Primary />

<Controls of={LoginSplashImageStories.Basic} />

## Guidance

- Keep the image decorative; do not place text or essential meaning only in the image.
- Pair it with a form column in desktop layouts.
- Hide it on narrow screens to preserve space for credentials and recovery actions.
