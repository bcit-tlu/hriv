## When to use

Use `AnnouncementBanner` for the active HRIV announcement fetched from the backend. It intentionally stays small: the component renders the message, chooses the app or login placement, and optionally exposes a dismiss action in the app shell.

## Interactive example

`Basic` is the best place to explore supported props. Designers and developers can use controls to try the HRIV placement variant and the curated MUI `Alert` presentation options.

<Primary />

<Controls of={AnnouncementBannerStories.Basic} />

## Implementation guidance

- Keep `variant="app"` for banners displayed inside the authenticated application shell.
- Use `variant="login"` when the banner appears above the login form.
- `alertVariant`, `severity`, and `color` are intentionally exposed because they map to safe MUI `Alert` presentation variants.
- `onDismiss` is callback behavior, so it is shown through the `With Dismiss Action` story rather than as a control.
