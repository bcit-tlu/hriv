## When to use

Use `FooterBar` at the bottom of the application shell and login screen. It exposes additional version links only to users who can manage users/admin areas.

## Interactive example

<Primary />

<Controls of={FooterBarStories.Basic} />

## Guidance

- Non-admin/student views show the repository link and optional send-feedback action.
- Admin-capable views include frontend, backend, and backup component versions.
- Version links point to releases when a concrete version is known, and to the repository when the value is `dev` or unavailable.
- Link styling follows the footer variants documented in `Components/Link`.
