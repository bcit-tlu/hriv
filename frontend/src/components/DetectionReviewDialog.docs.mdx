## When to use

Clicking a pending row's thumbnail on `MeasurementReviewPage` opens this
dialog: a bare OpenSeadragon view of the image — no annotations, counts or
toolbars — beside three instructor-facing controls (detection sensitivity,
minimum cell size, exclude purple-stained nuclei). Control changes debounce a
read-only `POST /measurement-findings/{id}/preview` and the readout shows the
proposed scale, objective, confidence and RBC evidence; **Apply** persists
the tuning via `PATCH` so a later approval promotes it into image metadata.
See `docs/measurement-review.md`.
