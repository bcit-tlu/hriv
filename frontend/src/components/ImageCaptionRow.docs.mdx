## When to use

`ImageCaptionRow` renders `[h2 image title] [Description: … …more] [🔒 Instructor note: … …more] {end}`.
Each text cell clamps to one line with an "…more" affordance; both open the caller's
`ViewportDialog` (`onShowNote`), whose body is `ImageNotesContent`. `end` carries the right-hand
actions (position readout, **Open image**, or the fitted collections cell). When either text is
present the title is capped at min(468px, 40%) so the text gets the room; without one the title
takes the full width.

The instructor note cell renders only when `instructorNote` has text. The API sends `null` to
students, so the component needs no role check; on narrow screens the row wraps instead of
squeezing both cells.

Used by `ImageViewerInfoBar`, `SequenceCollectionViewer`, and `SynchronizedCollectionViewer`.
