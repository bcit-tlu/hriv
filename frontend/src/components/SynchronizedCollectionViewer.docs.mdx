# SynchronizedCollectionViewer

Two read-only OpenSeadragon viewers side by side for `synchronized` collections, mounted by
`CollectionsPage` under the shared detail header (#1417).

## Layout

- The **first two visible members** render as left/right panes, each a read-only `ImageViewer`
  (`canEditContent={false}`, stored annotations/locked overlays/measurement from `metadataExtra`
  pass through without edit callbacks). More stored members produce a "Showing 2 of _N_" note —
  three/four-image layouts are future work.
- Each pane has a caption with the member name (plus an _inactive_ marker) and an **Open image**
  action that navigates to the regular `?image={id}` view where annotations can be edited.
- Fewer than two visible members shows a fallback alert with the ordered member list and
  per-row **Open image** links. Members whose tiles fail mid-session are skipped; if the failures
  leave fewer than two, the fallback explains that the images could not be loaded.

## Linked navigation

- Pan, zoom and rotation on either viewer mirror onto the other immediately (no spring lag) via
  raw `viewport-change` events exposed by `ImageViewer`'s `onViewerReady` prop. A re-entrancy
  guard prevents feedback loops, and programmatic writes (reset, follower updates) never lead
  the sync.
- The pair keeps a **relative offset** — the difference between the two viewports captured once
  both have opened — so images aligned around different highlights stay aligned. Re-ordering the
  offset is a multiplicative zoom ratio, an additive center delta and an additive rotation delta.
- **Link views** (the switch) toggles mirroring for everyone. Re-linking re-captures the current
  relative alignment instead of snapping one side to the other, which is how a new alignment is
  composed.

## Persisted view

`collection.viewport_state` maps `"<image_id>"` to `{ zoom, x, y, rotation }` — each pane's
absolute position (the offset between them is implicit). Entries that don't match the shape are
ignored.

- **Save view** (editors only) writes both panes' current viewports through
  `PUT /api/collections/{id}/viewport` (whole-replace, optimistic-concurrency `version`), so the
  saved pair restores exactly on reload and through `?collection={id}` share links.
- **Reset view** (everyone) re-applies the saved positions — or each viewer's home when nothing
  is saved — then re-arms the offset.
- Non-editors receive the saved view on load and may pan/zoom freely without persisting anything.

## Orientation

In `portrait` orientation a full-panel hint asks the user to rotate to landscape. The viewers
stay mounted underneath the overlay so rotating back restores the exact view rather than
re-opening the images.

## Stories

- **Basic** — two panes, linked, editor toolbar.
- **Larger Set** — the "Showing 2 of _N_" note.
- **Portrait Hint** — the orientation overlay (matchMedia is stubbed).
- **Read-Only Member** — no Save control without `can_edit`.
- **Too Few Images** — the fallback state with the member list.
