# Viewer side panel

A Markers-feature-only, permanent right-side panel for the image page and Sequence
viewer. One square OSD-style control opens it; the header's left-aligned exclusive
Markers, Shared View and Details buttons select content, and its right control closes it.
Selected buttons use MUI rounded-square action states, not navigation-rail pills.

At sm and above the panel reserves 256px and OSD resizes its actual image container:
the navigator, toolbar, floating cards and Sequence arrows remain in the image area.
At xs it overlays the full frame. Outside presses and Escape never close the panel;
Escape still belongs to placement, editing and menus.

Open state and selected content persist under `hrivpref:viewer-panel:user:<id>`.
New users start closed on Markers. Anonymous previews and storage failures use memory.
The list reuses the existing grouped visibility and row menus with a stable menu
portal container; the Details fields and Viewer controls reuse the legacy drawer's
content. Flag-off viewers and Synchronized panes retain their previous UI.
My and Instructor items are the only groups returned to viewer lists and markers;
other people's public views remain behind Public & shared Boards. The middle link
tab reuses the image page's copy action. Sequence copies a standalone image view
with live viewport and selection boxes. SharedView demonstrates the copy action.

Basic shows the closed control; Markers and Details exercise content and menus;
The Markers story uses Chromatic light, dark and mobile modes to cover the alternate
palette and full-width overlay without duplicating stories.

NewlySaved demonstrates the saved row's exclusive selection and DOM focus. Saving
a new view opens Markers if needed, expands its group and scrolls the row into view.
Rows, metadata and help use footer-sized caption typography. Group headings use
the slightly larger body2 hierarchy and show saved-view counts in parentheses.
The Markers tab no longer repeats a total-count heading below its controls;
Shared View and Details retain their section headings.
