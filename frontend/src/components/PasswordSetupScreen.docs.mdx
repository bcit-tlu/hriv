Guest password setup uses the shared login layout. The fragment token is kept in
memory after URL cleanup; submitting establishes the session without a second login.

<Primary />

Passwords require at least eight characters, at most 72 UTF-8 bytes, and matching
confirmation. Expired/replaced links, existing passwords, disabled accounts, and
throttling have actionable inline copy. Sign in instead returns to normal login.
