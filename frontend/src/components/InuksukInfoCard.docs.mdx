Marker clicks open a non-modal place card at the viewer's top-right, not an editor.
It shows the title, optional description, visible Board names and favourite state.
Only API-authorized editors see the pencil. There is no close X: outside pointer
presses deselect and dismiss it, while Escape also closes it. Marker presses select
that marker instead. Board-loading failures leave outside/Escape dismissal usable.

The favourite state is a read-only star at the right of the header,
with a tooltip and accessible name but no visible status sentence. It does not
toggle favourites; use Edit to change that value. Compact caption text matches
the page footer, with a subtitle2 title.

The pencil replaces the card content with the shared inline form: title,
description, checkbox Boards picker, title-row favourite star, Save changes/Cancel
and permitted, confirmed Delete. Drawer Edit selects and pans to the same marker,
focuses its row and opens this editor, never a central dialog. OCC versions, errors
and Reload current are unchanged. Cancel returns to the information card; Escape
explicitly cancels and closes it. Outside presses (including other markers or drawer
rows) keep an editor open, even if currently unchanged; use Save/Cancel/Escape first.
The portalled Boards menu stays usable in fullscreen and never discards edits.
