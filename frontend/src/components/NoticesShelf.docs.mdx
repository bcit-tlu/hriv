## Behaviour

- `selectNotices` keeps pinned + live posts from the shared feed, capped at three, in feed order.
- Card titles call `onOpenAnnouncements(id)`; "All announcements" opens the page unfocused.
- Reactions toggle through the same `useAnnouncements.toggleReaction` as the page and bell.
- The #1655 welcome message is a seeded pinned `everyone` announcement — no separate component.
