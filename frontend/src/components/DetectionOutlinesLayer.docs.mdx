## When to use

Rendered by `DetectionReviewDialog` over its bare OpenSeadragon viewer. The
preview endpoint's `include=outline` response is a labelled PNG in
work-image space (1 = counted but outside the dominant size window,
2 = selected); `detectionOutlines.ts` tints it — green for counted,
vermillion for rejected — and this layer blits it into `viewer.canvas`,
tracking zoom/pan like `CountOutlinesLayer`. The overlay is ephemeral
review UI: it is never persisted as annotations or metadata. Stories use a
deterministic fake viewer surface rather than a real tile source.
