<Title />

The feature-gated Boards utility opens `?page=boards`. Your Boards come first;
Shared with me / Public lists visible Boards you do not own. Covers contain up
to four authorized, renewing Inuksuk thumbnails. Recent Inuksuks use a responsive
column collage, with a server-side favourites filter and independent owner actions.

Selecting a Board shows its one-level Sections and Unsectioned members. The
page has its own handle-only dnd-kit provider, separate from Browse: reorder
owned Boards, Sections, or members, drop into an empty Section, or save an owned
Inuksuk to another editable Board. Move/Save to… is the explicit copy/move flow;
Section menu actions are a non-drag alternative. Failed reads never result in
partial assignment replacement. Conflicts require reloading the current data.

Cards open the existing shareable image viewer with the exact saved viewport;
browser Back restores the Board and Section URL. Board deletion warns that
otherwise orphaned Inuksuks will be deleted. Board removal instead preserves
the backend's last-Board guard.

## Collection saved views

With `features.inuksuks`, collection members have independent slot identities.
Several slots can show one source image without sharing selection, drag order,
or viewport state. The new saved-view story exercises this feature; legacy stories
keep the feature disabled. Slot crops and labels are snapshots, not editable links
to the original Inuksuks.
