  Colon-separated browse-location breadcrumb used by the manage tables: each ancestor segment is a

## When to use

`ManagePage` renders it in the Category column for images; `ManageCollectionsPage` renders the same
breadcrumb for each collection's filed category (#1554 — extracted from `ManagePage` so both tables
share the markup). Pass the flat category tree through `buildCategoryPaths` once per tree change and
hand the resulting map to each row.

## Implementation guidance

- **Segments link.** Each ancestor and the leaf call `onNavigate` with the path slice up to that
  depth; clicks stop propagation so table rows don't also fire their row action.
- **Fallbacks.** `categoryId: null` renders an em-dash (uncategorized / Browse root); an id missing
  from the map renders the raw id rather than crashing on a stale reference.
- **Hidden marker.** `getCategoryHiddenStateFromPath` decides the eye icon — pass the themed
  `hiddenColor` (visibility palette `inactive`) so the glyph matches each table's palette.
