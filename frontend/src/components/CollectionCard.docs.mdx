## When to use

Use `CollectionCard` inside the Collections tab grid (`CollectionsPage`) to represent one
`CollectionSummary`. Clicking the card body opens the collection (`?collection={id}`); the icon
buttons in the corner call `onEdit` / `onDelete`.

## Implementation guidance

- The cover is rendered through `RenewingThumbnail` with a collection-specific renewer, so an
  expired thumbnail token is refreshed via `GET /api/collections/{id}` rather than the image route.
- The type chip is outlined primary (`Synchronized` / `Sequence`); the visibility chip reuses the
  category restriction palette — `Restricted` borrows the group-chip colours, `Public` is neutral
  outlined, `Private` uses the muted visibility grey.
- Edit/delete icons are a UX gate only: they render when `permissions.canEdit` /
  `permissions.canDelete` is true **and** a handler is supplied. The backend re-checks authority on
  every call.
- Without a cover the card shows the collections icon on a primary-coloured block.
