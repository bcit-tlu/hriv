## When to use

The image view and both collection viewers render `ImageNotesContent` inside a `ViewportDialog`
whose title comes from `imageNotesTitle(description, instructorNote)`:

| Shown                | Title                             |
| -------------------- | --------------------------------- |
| Description only     | **Description**                   |
| Both                 | **Description & instructor note** |
| Instructor note only | **Instructor note**               |

With both, each gets a heading; with one, the title already names it. The instructor note section
ends with the "Visible to instructors, staff and admins" hint. Students never see it — the API
sends them `instructor_note: null`.
