## When to use

`App` renders the info bar directly below the regular image viewer. At `md` and up it is a
40/40/20 grid — Notes, Collections, and the viewer instructions — and empty Notes/Collections
cells still reserve their column so the instructions never move between images. Below `md` the
cells stack and empty ones collapse. Image metadata moved into the `ImageDetailsDrawer` overlay.
