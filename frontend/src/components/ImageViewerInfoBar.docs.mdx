## When to use

`App` renders the info bar directly below the regular image viewer. At `md` and up Notes and
Collections sit side by side in a 60/40 split favouring the note; a lone cell spans the full
width, and below `md` the cells stack.
Each value is clamped to two lines — when it overflows, an "…more" link at the end of the second
line opens a Popover with the full content. The bar renders nothing when both are absent; the viewer instructions live in
the `ImageDetailsDrawer` footer.
