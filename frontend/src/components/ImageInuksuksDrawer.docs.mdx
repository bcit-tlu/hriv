<Title />

The CompassCalibration trigger is an auto-fading TOP_LEFT OpenSeadragon control.
It has no number badge, matching adjacent white-on-dark viewer controls.
The left-anchored panel stops above the toolbar and stays inside the viewer in
full-page mode and shares its existing image-data request with the markers.

My and Instructor start expanded; Public starts collapsed. Each row has an
independent marker eye and a ⋮ menu for Show/Hide label and permitted Edit/Delete.
Group eyes control markers; group menus control labels. Group actions replace all row overrides
for that dimension; a later row action overrides the group. Mixed groups show
accessible “Mixed” states; clicking a mixed group shows all. Neither dimension hides
the other. A row navigates without opening an editor; the explicit owner edit
action opens the existing dialog. Rows have titles only; drafts appear as Unsaved
under My Inuksuks. Escape restores focus to the trigger when no draft needs cancelling.
Hover backgrounds span the full row, including the separate eye and options buttons.

Preferences are scoped to the signed-in user, bounded to 500 recent overrides,
and shared across synchronized panes and browser tabs. Sequence navigation
arrows hide while this panel is open, rather than painting over its rows.
