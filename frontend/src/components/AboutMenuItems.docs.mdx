## Behaviour

- `Documentation` shows only when `onOpenGuide` is given (admins/instructors); it calls
  `onNavigate` (close the popover) and then `onOpenGuide`.
- `About` opens the dialog without closing the popover — the dialog is rendered inside it — and
  calls `onNavigate` once the dialog closes.
