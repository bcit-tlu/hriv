## When to use

Render the standard contained **My collections** button on Browse when the personal-drawer feature
flag is enabled and the user has visible owned collections. The button sits above the always-visible
Browse footer. Opening it provides collection navigation, creation, and **See all** without adding
personal collections to the sortable Browse grid.

The always-mounted trigger button doubles as the sheet's title (`aria-labelledby`) and floats above
the sheet's bottom-left corner — the sheet slides up _beneath_ it. Tiles carry only the cover and
title (`density="minimal"`) to keep the drawer minimally invasive.

The temporary state shows a backdrop and closes on Escape. Pinning swaps the backdrop for reserved
page bottom space — the same sheet stays mounted in both modes, so pinning never reloads tiles.
Unpinning keeps the drawer open (the pin is not a close control). The sheet's bottom edge rides the
footer's live on-screen gap, so when the footer scrolls into view the sheet attaches to its top edge
and moves with it — it never covers the footer. Compact tiles are 160–180 px wide and scroll
horizontally below about 1424 px.
