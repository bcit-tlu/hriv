## When to use

Render the collapsed **My collections** button on Browse when the personal-drawer feature flag is
enabled and the user has visible owned collections. Opening it provides collection navigation,
creation, and **See all** without adding personal collections to the sortable Browse grid.

The temporary state uses a backdrop and closes during navigation. Pinning changes it to a persistent
surface that keeps Browse available and reserves enough bottom space to avoid covering the final
tile row.
