## When to use

The modal opens from the **Set cover image** overlay on a collection tile (the image icon,
top-right, `canEdit`-gated like the title edit pencil). The tile summary carries no member
list, so the caller loads the collection detail first and passes its `images` — visible
members only, in member order.

## Implementation guidance

- **Save pins a member.** `onSave` emits the picked image id and `blank=false`;
  the app PATCHes `cover_image_id` on the collection (clearing `cover_blank`).
- **"None" is the blank tile.** The first row emits `(null, true)` — the tile
  renders the type-logo placeholder like an uncovered category.
- **"Automatic" restores the fallback.** The second row emits `(null, false)` —
  clears both states so the tile uses the first member again; it is
  pre-selected when no cover is pinned and the blank flag is off.
- **Backend validation.** `PATCH /api/collections/{id}` 422s a `cover_image_id` that is
  not a member visible to the caller; removing the pinned member clears the pin, and
  deleting the image row clears it via `ON DELETE SET NULL`.
- **Invisible pins read as no pin.** If the pinned member is not visible to the viewer,
  summaries report `cover_image_id: null` and `cover_thumb` falls back to the first
  visible member.
