## When to use

`ClampedContent` renders content clamped to a fixed number of lines (`lines`, default 2). When it
overflows, an "…more" link at the end of the last visible line calls `onMore` — callers open the
full content in a `ViewportDialog`. It is shared by `ImageCaptionRow` (notes) and any clamped
link list.
