## When to use

`ClampedContent` renders content clamped to a fixed number of lines (`lines`, default 2). When it
overflows, an "…more" link at the end of the last visible line opens a Popover with the full
content (`fullContent`, defaulting to the children — pass the unflattened note for `pre-wrap`
output). It is shared by `ImageViewerInfoBar` and the collection-viewer caption rows.
