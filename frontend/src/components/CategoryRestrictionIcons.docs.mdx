## When to use

Use `CategoryRestrictionIcons` next to category labels in dense category-picker and category-management rows. The icons summarize backend-enforced visibility rules without replacing the detailed restriction controls in edit dialogs.

## Interactive example

`Basic` exposes the supported HRIV states as controls: program restrictions, group restrictions, inherited restriction styling, hidden-category muted styling, and clickable management affordances.

<Primary />

<Controls of={CategoryRestrictionIconsStories.Basic} />

## Implementation guidance

- Program restrictions use the primary colour and the tooltip `Restricted to specific programs`.
- Group restrictions use the secondary colour and the tooltip `Restricted to specific groups`.
- Inherited restrictions use the inherited opacity treatment and tooltip copy that names the parent source.
- Hidden categories mute both lock colours to the same action colour while preserving inherited opacity.
- In management contexts, pass click handlers so the locks render as MUI `IconButton` affordances. In read-only picker contexts, omit handlers so they render as labelled static icons.
