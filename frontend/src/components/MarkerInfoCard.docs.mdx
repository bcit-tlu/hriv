<Title />

Marker clicks open a non-modal place card at the viewer's top-right, not an editor.
It shows the title, optional description, visible Board names and favourite state.
Only API-authorized editors see the pencil. There is no close X: outside pointer
presses deselect and dismiss it, while Escape also closes it. Marker presses select
that marker instead. Board-loading failures leave outside/Escape dismissal usable.

The header keeps the Marker icon to the left of its subtitle2 title in both modes.
The pencil is immediately beside the title; the star stays at the far right.
For API-authorized editors the view-mode star toggles Favourite immediately through
the versioned API. It shows progress/errors and requires Reload current after a
conflict. Read-only users retain a non-interactive indicator. There is no visible
status sentence; compact caption text matches the page footer.

The pencil replaces the card content with the shared inline form: title,
checkbox Boards picker, title-row favourite star, Save/Cancel and permitted Delete.
Description starts collapsed under More options, retaining existing text without
auto-expansion. Delete opens a secondary confirmation dialog; cancelling it keeps
the editor draft. Drawer Edit selects and pans to the same marker,
focuses its row and opens this editor, never a central dialog. OCC versions, errors
and Reload current are unchanged. Cancel returns to the information card; Escape
explicitly cancels and closes it. Outside presses (including other markers or drawer
rows) keep an editor open, even if currently unchanged; use Save/Cancel/Escape first.
The Board chips and the portalled **…more** dialog stay usable in fullscreen and never discard edits.
