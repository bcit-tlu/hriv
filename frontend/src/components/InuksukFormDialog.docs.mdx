<Title />

Save an exact image position, zoom and rotation to one or more editable Boards.
Title and at least one Board are required.
The inline create action always makes a private Board and selects it.
The last successfully used Board is remembered per user; unavailable Boards are
never selected from storage.

Owner capabilities come from the API, not role guesses. Edits and confirmed
deletes send the current version. A stale-version response preserves the local
draft and offers **Reload current** before retrying. The dialog is contained in
the viewer during OSD full-page mode.

Viewer placement uses the non-modal top-right variant. The selected Title and
Board picker stay visible, while Description and Favourite start collapsed under
More options. Save keeps the viewer tool armed; Cancel or Escape removes its
draft marker and drawer row. The full dialog remains available for editing.

Successful creation reports the new record to the viewer, which selects its marker
and info card and focuses its selected panel row. Failed saves retain the draft.
Both variants use small inputs, body2 input text, caption guidance and tighter
spacing; the modal and placement form keep their existing keyboard behavior.
