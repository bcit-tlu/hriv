## When to use

Shared by the Edit image dialog's Measurement Settings and the Measurement
review table so both edit `measurement_scale` / `measurement_unit` the same
way. Units are µm, nm, mm and cm; a stored value outside that list (older
free-text entries) stays selectable rather than being dropped.

- Dialogs pass `scaleLabel` / `unitLabel` and `allowEmptyUnit` (adds **None**).
- Dense table rows use `size="small"` and `ariaLabel` (the image name) instead
  of visible labels.

The scale field keeps `type="number"` and a minimum width so the spinner
arrows never cover the value.
