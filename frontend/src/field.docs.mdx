## How to use fields

HRIV uses MUI `TextField` directly. Prefer `variant="standard"` for login and compact form fields unless a denser or more prominent form layout requires `outlined` or `filled`.

## Guidance

- Use clear labels; placeholders should provide examples, not replace labels.
- Use `helperText` for validation or clarification that helps users complete the field.
- Use `error` with helper text so the failure is visible and understandable.
- Use adornments for field-specific actions such as toggling password visibility.
- Keep credential fields full-width in the login column.
