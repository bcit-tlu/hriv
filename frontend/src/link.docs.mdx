## How to use links

HRIV uses MUI `Link` for both true anchors and button-style navigation actions. Use real anchors for external destinations and `component="button"` for in-app actions that do not navigate by URL.

## Guidance

- Use `underline="hover"` for most navigation and footer links.
- Use `underline="always"` for compact status/log actions that need stronger affordance.
- Use `variant="caption"` with `color="text.secondary"` in the footer.
- Use `component="button"` for breadcrumbs and in-app state transitions.
- External links should include `target="_blank"` and `rel="noopener noreferrer"`.
